# 保险产品页 P1/P2 交互录制压力测试设计

## 1. 目标

在现有 DataInsights 本地保险产品 Demo 中增加一组确定性、无外网依赖的复杂交互，用于人工和自动化验证 rrweb 对动态 DOM、滚动、输入、嵌套浏览上下文及非 DOM 渲染内容的录制与回放效果。

本功能是 Demo 测试能力，不改变 DataInsights SDK 公共 API，不修改 rrweb 核心，也不要求页面业务流程合理。

## 2. 设计原则

- 所有页面、数据和资源均保存在本地，不连接真实保险、医院、支付或身份系统。
- 交互结果必须能通过稳定的 DOM 状态观察，便于录制、回放和自动化断言。
- 对 rrweb 默认无法完整还原的内容明确展示能力边界，不用 DOM 伪造“完整支持”。
- 不采集上传文件正文、真实个人资料、生物识别信息或摄像头内容。
- 不增加生产 SDK 配置项；必要的辅助事件只包含固定代码、计数和状态，不包含自由文本或文件内容。
- 继续使用当前点击授权后才开始录制的规则。

## 3. 页面结构

在现有产品详情和投保表单之间增加“复杂交互录制实验室”区域。实验室按 P1 和 P2 分组，每个组件显示：

- 交互名称；
- 当前状态；
- 预期录制结果；
- 对于能力边界，显示“完整还原”“仅状态可见”或“默认不录制”。

实验室不参与投保提交门禁，避免和已有五份保险须知流程耦合。

## 4. P1 交互组件

### 4.1 页签与手风琴

- 提供三个保障页签，每次只显示一个动态面板。
- 提供至少四个可独立展开、收起的手风琴项目。
- 页签和手风琴均维护 `aria-selected` / `aria-expanded`，并使用显式 DOM 状态类。
- 回放应恢复最后选中的页签及各手风琴展开状态。

### 4.2 搜索联想与键盘选择

- 本地内置医院、药品和职业候选数据，不发起网络请求。
- 输入后按子串过滤候选项，支持方向键移动高亮、Enter 选择和 Escape 关闭。
- 页面显示已选择项目及搜索状态。
- 清空输入后恢复初始状态；无匹配时显示空结果提示。
- 不发送用户输入内容到自定义事件。

### 4.3 横向滑动方案卡

- 使用原生横向滚动与 CSS Scroll Snap 展示至少六张方案卡。
- 同时提供上一项、下一项按钮，保证桌面自动化可以稳定操作。
- 当前卡片通过 Intersection/滚动位置或按钮行为更新 DOM 指示器。
- 录制应包含横向滚动过程和最终卡片状态。

### 4.4 Toast 与短暂状态

- 提供成功、警告、失败三种 Toast。
- Toast 使用固定持续时间自动消失，也可手动关闭。
- 页面保留最近一次 Toast 类型和累计次数，确保回放结束后仍可验证结果。
- Toast 文本使用本地固定文案，不包含用户输入。

### 4.5 虚拟长列表

- 内置至少 200 条模拟医院数据。
- 视窗只渲染当前窗口及上下缓冲项，通过顶部、底部占位高度维持滚动尺寸。
- 页面显示当前可见索引范围及最后选择项。
- 回放需要验证 DOM 节点回收、滚动位置变化和最终选择状态，不要求逐像素一致。

### 4.6 文件上传元数据

- 使用原生单文件选择控件，仅允许本地测试用的图片或 PDF。
- 页面只展示经过文本转义的文件名、MIME 类型和字节数，不读取或展示文件正文。
- 允许清除选择并恢复空状态。
- 自动化使用内存生成的测试文件；录制数据不得出现文件正文和本机绝对路径。

### 4.7 页面恢复

- 实验室状态写入 `sessionStorage`，仅保存固定组件状态、索引和计数。
- 提供“刷新并恢复实验室”按钮执行真实页面刷新。
- 刷新后恢复可序列化状态；临时 Toast、搜索候选和文件对象不恢复。
- SDK 的 Trace/Session 行为继续遵循现有契约，本组件不自行生成业务 Journey ID。

## 5. P2 能力边界组件

### 5.1 Canvas 手写轨迹

- 提供支持 Pointer Events 的 Canvas，可绘制、清除并完成签名。
- DOM 显示轨迹段数、是否已完成和最后操作。
- 当前 rrweb 配置未启用 Canvas 插件，因此回放不保证还原像素轨迹；应能还原外围 DOM 状态。
- 完成操作只发送固定的轨迹段数，不发送像素、坐标序列或签名内容。

### 5.2 WebGL 动画

- 使用原生 WebGL 绘制简单的旋转色块；不可用时显示稳定的降级信息。
- 提供开始、暂停和重置按钮，DOM 显示运行状态及帧计数区间。
- rrweb 默认不录制 WebGL 帧；回放只验证控制操作和 DOM 状态，不声明画面可还原。

### 5.3 同源 iframe

- 使用本地同源页面，包含按钮、输入框、计数器和滚动区域。
- 验证 iframe 内 DOM 交互在当前 rrweb 配置下的实际录制结果。
- iframe 页面不自行加载 DataInsights SDK，避免重复录制实例。

### 5.4 跨域 iframe

- 使用同一 Demo 服务的 `localhost` 与 `127.0.0.1` 主机名差异构造跨源页面，不访问外网。
- 父页面只显示加载成功状态，不能读取 iframe DOM。
- 默认预期为 iframe 内操作不被父页面 SDK 录制；自动化只验证隔离边界和父页面稳定性。

### 5.5 本地 PDF 阅读器模拟

- 采用同源 iframe 构建确定性的多页文档阅读器，提供翻页、缩放、滚动和页码状态。
- 该组件用于验证“嵌套阅读器交互”，不冒充浏览器原生 PDF 插件。
- 页面明确说明：浏览器原生 PDF 插件的内部 UI 通常不属于可录制 DOM，需另行评估。

### 5.6 权限型媒体边界

- 不主动申请摄像头、麦克风或活体检测权限。
- 使用静态状态卡说明这些媒体流和浏览器权限 UI 不应被录制。
- 提供“模拟授权结果”按钮，仅改变本地 DOM 状态，用于测试宿主页面对授权结果的展示。

## 6. 代码边界

为避免继续扩大现有 `app.js`，复杂交互采用独立资源：

- `examples/insurance-product/interaction-lab.js`：P1/P2 组件状态和事件。
- `examples/insurance-product/interaction-lab.css`：实验室组件样式。
- `examples/insurance-product/iframe-lab.html`：同源与跨源 iframe 测试内容。
- `examples/insurance-product/pdf-reader.html`：本地 PDF 阅读器模拟。
- `test/insurance-interaction-lab.e2e.test.ts`：独立真实浏览器录制/回放测试。

现有 `index.html` 只增加实验室结构及资源引用；`app.js` 继续负责产品投保和保险须知流程。

## 7. 状态与事件

实验室使用单一版本化状态对象：

```js
{
  version: 1,
  selectedTab: 'medical',
  expandedPanels: [],
  selectedSuggestion: null,
  activeSlide: 0,
  toastCount: 0,
  virtualRange: [0, 0],
  selectedVirtualItem: null,
  canvasStrokeCount: 0,
  canvasCompleted: false,
  webglState: 'idle',
  mediaPermissionState: 'not-requested'
}
```

只在以下完成节点发送固定名称的自定义事件：

- `interaction-lab-checkpoint`：人工点击“记录当前实验状态”时发送一次当前固定状态摘要。
- `canvas-signature-completed`：只包含轨迹段数，不含坐标和像素。

文件名、搜索输入、iframe 输入和自由文本不得进入自定义事件。

## 8. 错误处理

- WebGL、Canvas Context 或 sessionStorage 不可用时局部降级，不影响产品页和 SDK。
- iframe 加载失败时显示本地错误状态，不自动重试外网。
- 虚拟列表的索引必须限制在合法范围，快速滚动不得产生负占位高度。
- 上传不支持的文件时只显示本地校验提示，不读取文件。
- 所有事件监听器仅绑定一次，不创建无上限定时器；WebGL 动画在页面隐藏或暂停时停止。

## 9. 自动化验收

真实 Chrome E2E 应覆盖：

1. 页签、手风琴、搜索键盘选择、横向滚动、Toast 和虚拟列表产生预期 DOM 状态。
2. 上传元数据可见，但录制序列中没有文件正文和绝对路径。
3. Canvas 操作记录外围状态；测试明确断言当前配置没有 Canvas 插件承诺。
4. WebGL 支持和降级路径均不导致页面异常。
5. 同源 iframe 完成交互；跨源 iframe 对父页面保持不可读。
6. PDF 阅读器模拟完成翻页和缩放，最终页码可在回放中观察。
7. 刷新后恢复允许持久化的实验室状态。
8. 最终回放恢复关键 DOM 状态，播放器现有速度、进度条、沙箱及密码保护断言不回归。
9. 全部请求仅访问 `127.0.0.1` 或 `localhost`。

## 10. 非目标

- 不启用 rrweb Canvas 插件或跨域 iframe 协作协议。
- 不录制真实 PDF 插件内部 UI、摄像头、麦克风或活体影像。
- 不实现通用组件库、真实业务接口或后台存储。
- 不把这些 Demo 组件变成 SDK API。
- 不改变保险须知确认和投保提交规则。
